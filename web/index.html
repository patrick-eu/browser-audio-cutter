    How to cut audio online

    1. Drop an audio file into the box above or tap Choose audio file.
    2. Drag the two handles on the waveform, or type the start and end time in seconds.
    3. Add a fade in or fade out if you want, then press Play region to hear the cut.
    4. Need more than one clip? Press + Add region and mark another part.
    5. Pick MP3 or WAV and press Download next to each region.

    Audio cutter FAQ

    Is my audio uploaded?

    No. The file is decoded, cut and encoded by this page inside your browser. The only files your browser downloads are this page and its two scripts, both from this site.

    Which formats can I export?

    MP3 at 128, 192, 256 or 320 kbps, or WAV as 16-bit PCM. Both are written at 44.1 kHz, in stereo for stereo sources and mono for mono sources.

    MP3 or WAV?

    WAV contains exactly the samples between your start and end times. MP3 is smaller, but MP3 encoding adds a short stretch of silence at the start of the file and the audio is re-compressed, so pick WAV when the exact cut point matters.

    Is there a file size or length limit?

    This page sets none. The whole decoded file is kept in memory while you edit, so very long files need more memory and the practical limit depends on your device.
